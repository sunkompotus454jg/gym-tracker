# Дневник тренировок

Программа верх/низ на 4 дня (Пн, Вт, Чт, Пт) и дневник подходов: вес, повторы, «прошлый раз», подсказка «Пора добавить вес», видео по технике, журнал и лучший вес.

## Как выложить на GitHub Pages

1. Загрузи все файлы из этой папки в корень репозитория: **Add file → Upload files**, перетащи файлы, **Commit changes**.
2. Открой **Settings → Pages**.
3. В **Source** выбери **Deploy from a branch**, ветка `main`, папка `/ (root)`, нажми **Save**.
4. Через 1–2 минуты приложение будет доступно по адресу
   `https://sunkompotus454jg.github.io/gym-tracker/`

## Как поставить на телефон

- **iPhone (Safari):** открыть ссылку → кнопка «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Добавить на главный экран» / «Установить приложение».

С главного экрана приложение открывается как обычное и работает без интернета (кроме видео).

## Где хранятся данные

Только в памяти браузера на телефоне. На сервер ничего не отправляется.
Раз в пару недель стоит нажимать **Журнал → Сохранить копию**: скачается файл `.json`.
Восстановить: **Журнал → Восстановить из файла**.

## Как обновить приложение

Загрузи новый `index.html` поверх старого. Если поменял `sw.js`, увеличь в нём номер `gym-tracker-v1` → `v2`, чтобы телефоны точно подхватили новую версию.
